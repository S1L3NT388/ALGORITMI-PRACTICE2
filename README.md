# Багатовимірні масиви

Програма для лабораторної: генерація та обробка двовимірних масивів (матриць).

## Що реалізовано

* Допоміжні методи: генерація матриці m x n випадкових чисел у заданому діапазоні та виведення матриці у вигляді таблиці з підписами рядків і стовпців
1. Віднімання від елементів кожного рядка середнього арифметичного цього рядка
2. Циклічний зсув матриці на k позицій вправо та на k позицій догори
3. Пошук максимальних елементів матриці та видалення рядків і стовпців, що їх містять
4. Обертання квадратної матриці на 90 градусів за годинниковою стрілкою in-place, без додаткового масиву

## Файл

- `task.py` — реалізація на Python

## Запуск
python task.py

Матриці для тестів генеруються випадково, тому результати щоразу трохи відрізняються. Обертання на 90 градусів (завдання 4) працює лише для квадратної матриці.
